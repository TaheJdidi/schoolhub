# PostgreSQL plutôt que SQL Server

SQL Server est le choix habituel avec .NET, mais la base de SchoolHub est PostgreSQL. Il est gratuit, proposé par tous les hébergeurs, et bien pris en charge par EF Core grâce à Npgsql. SQL Server demande une licence payante au-delà de l'édition Express, limitée à 10 Go par base.

*Décidé le 31/10/2026, [ticket 12](../wayfinder/cadrage-mvp/issues/12-architecture-technique.md), Q2.*
